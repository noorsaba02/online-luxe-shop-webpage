## 📌 Project Overview

**Project Name:** Luxe Shop - E-Commerce Web Application

**Description:** Luxe Shop is a responsive e-commerce web application built with React.js. Users can browse products, search, filter and sort them, view product details, and manage a shopping cart and wishlist with a dynamic, user-friendly interface.

**Goal:** To build a clean, responsive online shopping experience while practicing React components, state management and reusable UI design.

---

## ✨ Features

1. 🔍 **Product search** to find items quickly
2. 🎯 **Filter and sort** products by category, price and more
3. 🛒 **Shopping cart** with dynamic UI updates
4. ❤️ **Wishlist management**
5. 📄 **Product detail views**
6. 🔔 **Toast notifications** for instant user feedback
7. 🧩 **Reusable UI components** built with CSS modules
8. 📱 **Responsive design** for different screen sizes

## 🏗️ How It Works

- The app is built from **reusable React components** (product card, cart, wishlist, navigation and so on).
- **State** (using React hooks) keeps track of the cart, wishlist and search/filter/sort options, and the UI updates instantly when it changes.
- **Toast notifications** confirm actions such as adding an item to the cart or wishlist.
- **CSS modules** keep the styles scoped to each component.

## 🚀 Installation and Setup

### Prerequisites
- Node.js and npm installed

### 1. Clone the repository
```bash
git clone https://github.com/noorsaba02/Luxe-Shop--E-Commerce-Web-Application-.git
```

### 2. Go to the project folder
```bash
cd Luxe-Shop--E-Commerce-Web-Application-
```

### 3. Install dependencies
```bash
npm install
```

### 4. Start the application
Check the `scripts` section in your `package.json`, then run one of these:

**Vite:**
```bash
npm run dev
```
Opens at `http://localhost:5173`

**Create React App:**
```bash
npm start
```
Opens at `http://localhost:3000`
